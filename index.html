📊 구글 시트 연동

시트에는 착용데이터, 공식사이즈표, 유저제출 탭이 자동 생성돼요.
공식 사이즈표는 시트의 공식사이즈표 탭에 직접 입력하세요.

설정 방법을 모르면 아래 '설정 방법 보기' 를 눌러보세요
원본입력 탭에 데이터 붙여넣기 → "원본입력 → 앱으로 가져오기" 클릭 → 앱에 반영
앱 데이터를 시트에 백업하고 싶을 때만 "앱 → 착용데이터로 내보내기" 사용
⚙️ Apps Script 설정 방법 보기
1단계 — 구글 시트 열기
2단계 — 상단 메뉴 [확장 프로그램] → [Apps Script] 클릭
3단계 — 열린 창에 있는 기존 코드 전부 지우고, 제가 드린 apps-script.gs 파일 내용 전체 붙여넣기
4단계 — 💾 저장 버튼 클릭
5단계 — [배포] → [새 배포] 클릭
6단계 — 유형: 웹 앱 선택
7단계 — "다음 사용자로 실행": 나(내 계정) 선택
          "액세스 권한": 모든 사람 선택
8단계 — [배포] 클릭 → 권한 허용 → URL 복사
9단계 — 복사한 URL을 위 입력칸에 붙여넣기 ✅
